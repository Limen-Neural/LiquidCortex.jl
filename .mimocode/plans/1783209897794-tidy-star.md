## Phase 3: Remove Market/Mining Telemetry (#7)

This is the main refactoring. Goal: make LiquidCortex.jl a **generic LSM/reservoir computing library** with no domain-specific code. All market/mining code is deleted — no adapter packages, no compatibility shims.

### 3.1 Make dimensions configurable

**`src/sparse_brain.jl`**:
- Change `N_IN = 14` and `N_OUT = 16` from `const` to constructor parameters
- `SparseBrain(tau_m; n_in, n_out, name="default")` — default values can stay for backward compat
- `EnsembleBrain(; n_in=14, n_out=16)` — pass through to each lobe
- Update `XAVIER_STD_IN` and `XAVIER_STD_OUT` to compute from actual dimensions
- Update all hardcoded size references in comments

### 3.2 Delete MarketPulse and domain-specific decoding

**Delete `src/market_pulse.jl` entirely** — 100% domain-specific (cryptocurrency names, dYdX, Qubic, hardware proprioception). No replacement, no adapter.

**`src/LiquidCortex.jl`**:
- Remove `include("market_pulse.jl")`
- Remove exports: `MarketPulse`, `decode_market_pulse`, `pulse_to_input`
- Update module docstring to remove market references

### 3.3 Make global inhibition generic

**`src/sparse_brain.jl`** — `step!()`:
- Current signature: `step!(brain, u, gpu_temp, basys_load; funding_rate, liquidation_vol, reflex_eta, dydx_oi_delta, dydx_funding_rate)`
- New signature: `step!(brain, u; inhibition=0.0f0, reflex_eta=ETA)`
  - `inhibition` is a generic [0, N] stress signal the caller computes externally
  - Remove all market-specific keyword args (funding_rate, liquidation_vol, dydx_oi_delta, dydx_funding_rate)
  - Remove the internal market inhibition logic (lines 253-269 in sparse_brain.jl)
  - Keep hardware inhibition (gpu_temp, basys_load) OR make it generic too
  - **Decision**: Make fully generic — caller provides a single `inhibition` float. Hardware proprioception belongs in the application layer, not the reservoir core.

- `ensemble_step!()`:
  - Current: `ensemble_step!(eb, u, gpu_temp, basys_load, funding_rate, liquidation_vol, liquidity_delta; ...)`
  - New: `ensemble_step!(eb, u; inhibition=0.0f0, reflex_eta=ETA, reflex_signal=0.0f0)`
    - `reflex_signal` replaces `liquidity_delta` — when `|reflex_signal| > threshold`, Fast lobe gets boosted STDP

- `step!(eb::EnsembleBrain, ...)` — same simplification

### 3.4 Remove Monte Carlo simulation

**`src/sparse_brain.jl`**:
- Delete `monte_carlo_paths!()` function entirely — it's a market-specific GPU workload (Geometric Brownian Motion price paths)
- Remove the MC buffer comment from VRAM estimate in header

### 3.5 Rename market_lsm.jl → reference_lsm.jl

**Rename `src/market_lsm.jl` → `src/reference_lsm.jl`**:
- The file is a 2,048-neuron reference reservoir — rename to remove "market" from filename
- Update the `include()` in `src/LiquidCortex.jl`
- Add SPDX header

### 3.6 Remove N_ASSETS constant

- `N_ASSETS = 7` in sparse_brain.jl is market-specific — delete it

### 3.7 Update module docstring

**`src/LiquidCortex.jl`**:
- Remove references to "MarketPulse", "market integration", "financial time-series"
- Describe as generic LSM for reservoir computing / neuromorphic experiments

## Risk Notes

- **Breaking change**: Removes `MarketPulse`, `decode_market_pulse`, `pulse_to_input` from the public API. Any downstream code using these will break.
- **API change**: `step!()` signature changes significantly (fewer positional args, different keyword args).
- **No compatibility layer**: Issue #7 explicitly calls for removal, not extraction. No adapter packages, no deprecation shims. Clean break at v0.2.0 pre-1.0.
